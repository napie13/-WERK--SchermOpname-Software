# Examenopname

Neemt het scherm van een leerling op tijdens een digitaal examen, zodat een school achteraf kan nagaan of er gefraudeerd werd. Gratis, eenvoudig en uitgerold via Intune.

- De leerling start de opname zelf en ziet altijd een venster met een rode rand.
- Alleen een leerkracht kan de opname stoppen, met een paswoord.
- Valt de opname weg, dan start ze vanzelf opnieuw. Alles wordt genoteerd in een logboek.
- Opnames blijven op de laptop, leerlingen kunnen ze niet verwijderen.

## Snel aan de slag

1. Dubbelklik op **Maak.cmd**. Overloop de instellingen, kies een leerkrachtpaswoord en wacht tot het pakket klaar is.
2. Zet `uitvoer\Examenopname-<versie>.intunewin` in Intune als Win32-app. De instellingen staan in de technische handleiding.
3. Druk de handleiding voor leerkrachten en leerlingen af.
